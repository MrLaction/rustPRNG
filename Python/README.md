# Versión Python

Implementación en Python de los tres generadores y del CLI del proyecto Rust. Solo necesita Python 3.10 o posterior; usa únicamente la biblioteca estándar.

Desde la carpeta raíz del repositorio, ejecutar:

```text
python3 python/main.py
```

Se puede elegir SHA-256 Counter, ChaCha20 o Blum Blum Shub. Los tres generan números de 40 dígitos y conservan el mismo formato de prompts y resultados que el programa Rust.
